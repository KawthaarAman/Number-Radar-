
# Game name 
Number Radar 

## Descreption 
A simple yet engaging game where the player tries to guess a randomly generated secret number. With each guess, the game gives instant feedback ("Too High" or "Too Low") to guide the player toward the correct answer in the fewest attempts possible.

## Technologies used 
1. HTML 
2. CSS
3. JavaScript 

## User Stories 
1. As a User, I want the system to randomly generate a secret number within a defined range at the start of each game, so that every round offers a fresh and unpredictable challenge.

2. As a User, I want to enter my numerical guess into the system, so that I can try to match the secret number.

3. As a User, I want the game to tell me whether my guess is too high or too low, so that I can adjust my next guess logically.

4. As a User, I want the game to congratulate me and display how many total tries it took when I guess the right number, so that I know I won and can see my performance score.

5. As a User, I want to experience a maximum limit on my number of attempts, so that the game has higher stakes and tension.
